## 🧑‍🏫 怎麼開始用呢？

---

### 📥 桌面版安裝教學（給愛動手的你！）

如果你喜歡把程式裝在電腦裡，這樣做就對了！👇

1.  打開你的命令提示字元或終端機，輸入：
    ```
    git clone [https://github.com/backup0821/Better-vegetable-catcher.git](https://github.com/backup0821/Better-vegetable-catcher.git)
    ```
2.  然後進入專案資料夾：
    ```
    cd Better-vegetable-catcher
    ```
3.  安裝需要的套件：
    ```
    pip install -r requirements.txt
    ```
4.  最後，執行主程式：
    ```
    python main.py
    ```
或者，你也可以直接到我們的發布頁面下載 **.exe 執行檔**，點兩下就能用囉！超簡單吧！🤩

---

### 🌐 網頁版使用教學（懶人福音！）

不想安裝？沒問題！直接打開網頁就能用囉！🥳

* 打開 `web/index.html` 檔案，或把它部署到 GitHub Pages 上。
* 更簡單的方法是，直接點擊我們的官方網站：[https://backup0821.github.io/Better-vegetable-catcher/WEB](https://backup0821.github.io/Better-vegetable-catcher/WEB)
手機瀏覽也沒問題！網頁會自動適應你的螢幕尺寸喔！📲

---

### 📊 功能怎麼操作？（新手上路不迷路！）

1.  點一下「**查詢作物**」，就可以選擇你想看的蔬果品項和市場囉！🔍
2.  切換到「**預測模式**」，就能看到未來價格的走勢圖了！🔮
3.  點擊任何圖表，還能查看詳細的數據和說明喔！🔢
