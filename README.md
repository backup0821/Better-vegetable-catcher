🧑‍🏫 使用教學

📥 安裝方式（桌面版）
```
git clone https://github.com/backup0821/Better-vegetable-catcher.git
cd Better-vegetable-catcher/desktop
pip install -r requirements.txt
python main.py
```
或
Realse介面中，下載exe執行檔


🌐 網頁版使用

開啟 web/index.html 或部署至 GitHub Pages
或使用官方架設之網站
https://backup0821.github.io/Better-vegetable-catcher/WEB

手機版支援 RWD，自動適應螢幕尺寸

📊 功能操作

✅ 點選「查詢作物」可選擇品項與市場

✅ 切換「預測模式」可查看未來價格走勢

✅ 點擊圖表可查看詳細數據與說明
