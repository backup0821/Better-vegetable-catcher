## 🎯 專案簡介

**農產品交易資料分析系統** 是一個專為農產品交易者、農民和市場分析師設計的智慧化資料分析平台。透過整合農業部開放資料，提供即時價格查詢、趨勢分析、季節性預測等功能，幫助使用者做出更明智的交易決策。

## ✨ 主要功能

### 📊 資料分析功能
- **價格趨勢分析** 📈 - 即時顯示農產品價格變化趨勢
- **交易量分布** 📊 - 分析不同時期的交易量分布情況
- **價格分布統計** 📉 - 統計價格區間分布，了解市場價格結構
- **季節性分析** 🌱 - 分析農產品的季節性價格變化模式
- **價格預測** 🔮 - 基於歷史資料的價格趨勢預測

### 🔔 智慧通知系統
- **價格異常通知** ⚠️ - 當價格出現異常波動時自動通知
- **市場休市提醒** 🏪 - 提醒市場休市時間
- **系統更新通知** 🔄 - 新版本發布時自動通知
- **維護狀態通知** 🛠️ - 系統維護時的通知

### 📱 多平台體驗
- **響應式設計** 📱 - 完美適配手機、平板、電腦
- **PWA 支援** 📲 - 可安裝為手機應用程式
- **電視看板模式** 📺 - 專為市場大螢幕設計的顯示模式
- **離線功能** 🔌 - 支援離線瀏覽和資料快取

## 🚀 快速開始

### 1. 線上使用
直接訪問我們的網站：

https://backup0821.github.io/Better-vegetable-catcher/WEB


### 2. 本地部署
```bash
# 克隆專案
git clone https://github.com/backup0821/Better-vegetable-catcher.git

# 進入專案目錄
cd Better-vegetable-catcher/WEB

# 啟動本地伺服器
python -m http.server 8000
# 或使用 Node.js
npx serve .

# 開啟瀏覽器訪問
http://localhost:8000
```

### 3. PWA 安裝
1. 在手機瀏覽器中開啟網站
2. 點擊「安裝」或「新增到主畫面」
3. 享受原生應用程式般的體驗

## 圖標更新功能

### 如何更換應用程式圖標

1. **選擇圖標**：在應用程式主頁面找到「選擇應用程式圖示」區塊
2. **預覽圖標**：點擊「預覽圖示」按鈕查看不同平台的顯示效果
3. **套用變更**：選擇想要的圖標後，系統會自動更新
4. **重新安裝**：如果桌面圖標沒有立即更新，點擊「重新安裝應用」按鈕

### 圖標類型

- **經典扁平**：簡潔的扁平化設計
- **立體質感**：具有玻璃感 UI 效果的立體設計（New! UI3.0 beta）

### 桌面圖標更新說明

由於瀏覽器快取機制，更換圖標後桌面上的圖標可能不會立即更新。解決方法：

1. **自動更新**：系統會自動嘗試更新 PWA 快取
2. **手動重新安裝**：點擊「重新安裝應用」按鈕強制更新
3. **瀏覽器重新安裝**：在瀏覽器中手動重新安裝 PWA

### 技術實現

- 動態更新 `manifest.json` 檔案
- 即時通知 Service Worker 更新圖標
- 自動清除相關快取
- 支援多種圖標格式和尺寸

## 使用說明

1. **選擇作物**：在資料分析頁面選擇要分析的作物
2. **選擇市場**：可選擇單一或多個市場進行比較

4. **設定預警**：在價格預警頁面設定價格監控

6. **自訂設定**：根據需求調整系統設定
