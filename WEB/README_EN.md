## 🎯 Project Introduction

**Better Vegetable Catcher** is an intelligent data analysis platform designed for agricultural product traders, farmers, and market analysts. By integrating open data from the Ministry of Agriculture, it provides real-time price queries, trend analysis, seasonal forecasts, and more to help users make smarter trading decisions.

## ✨ Main Features

### 📊 Data Analysis
- **Price Trend Analysis** 📈 - Real-time display of agricultural product price trends
- **Volume Distribution** 📊 - Analyze trading volume distribution over different periods
- **Price Distribution Statistics** 📉 - Understand market price structure
- **Seasonal Analysis** 🌱 - Analyze seasonal price patterns
- **Price Prediction** 🔮 - Forecast price trends based on historical data

### 🔔 Smart Notification System
- **Abnormal Price Alerts** ⚠️ - Automatic notification for abnormal price fluctuations
- **Market Closure Reminders** 🏪 - Remind users of market closure times
- **System Update Notifications** 🔄 - Notify users of new version releases
- **Maintenance Notifications** 🛠️ - Notify users during system maintenance

### 📱 Multi-Platform Experience
- **Responsive Design** 📱 - Perfectly adapts to mobile, tablet, and desktop
- **PWA Support** 📲 - Installable as a mobile app
- **TV Display Mode** 📺 - Special mode for market big screens
- **Offline Functionality** 🔌 - Supports offline browsing and data caching

## 🚀 Getting Started

### 1. Online Usage
Visit our website directly:
```
https://backup0821.github.io/Better-vegetable-catcher/
```

### 2. Local Deployment
```bash
# Clone the project
git clone https://github.com/backup0821/Better-vegetable-catcher.git

# Enter the project directory
cd Better-vegetable-catcher/WEB

# Start a local server
python -m http.server 8000
# Or use Node.js
npx serve .

# Open your browser
http://localhost:8000
```

### 3. PWA Installation
1. Open the website in your mobile browser
2. Tap "Install" or "Add to Home Screen"
3. Enjoy an app-like experience

## 🔧 Technical Architecture

### Frontend
- **HTML5** + **CSS3** + **JavaScript (ES6+)**

- **PWA** - Progressive Web App
- **Service Worker** - Offline support

### Data Handling
